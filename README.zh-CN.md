> Obsidian 插件：自动识别仓库中非 UTF-8 编码的文件，在**安全保护**前提下转换为 UTF-8；附带实验性**乱码修复**命令，可修复已烤进 UTF-8 内容的二次编码乱码。

英文版本：[README.md](README.md)

Obsidian 内部把所有笔记按 UTF-8 读取。一旦仓库里混入 GBK、Big5、Shift-JIS、UTF-16 等旧编码文件，打开就会乱码。本插件提供**探测 → 备份 → 转换 → 去 BOM** 的完整闭环，并内置多重"安全阀"，使任何误判都不可能不可逆地损坏你的笔记。

---

## 核心特性

- **严格 UTF-8 校验** —— 合法 UTF-8 文件（含纯 ASCII）原样放行。零风险。
- **BOM 强信号识别** —— UTF-8、UTF-16 LE/BE、UTF-32 的字节序标记直接信任。
- **候选编码评分探测** —— 在覆盖 10 大语种族、共 22 种候选编码之间做解码质量评分。
- **置信度保护** —— 低于阈值（默认 80%）的文件绝不静默转换，逐个由你确认。
- **转换前自动备份** —— 随时可以回滚。
- **乱码修复（实验性）** —— 修复 `ÖÐÎÄ`、`涓枃` 这类二次编码乱码，采用三重质量门槛、逐行修复与前后预览。
- **U+FFFD 损伤检测** —— 统计替换字符数量，并明确告知字节已丢失、无法自动恢复。绝不编造内容。
- **界面 10 国语言 + RTL** —— 简体中文、英语、日语、韩语、俄语、法语、德语、西班牙语、葡萄牙语、阿拉伯语。前 4 种免费，后 6 种需 VIP。
- **导出转换日志** —— JSON 或 Markdown。
- **VIP（可选）** —— 离线 Ed25519 激活码（通用码或绑定设备），解锁文件夹批量转换、后 6 种界面语言与编辑扩展名白名单，同时隐藏支持者横幅。
- **隐私** —— 完全无网络请求、无遥测。

## 安装

1. 打开**设置 → 社区插件 → 浏览**，安装 **Code Converter**。
2. 启用该插件。

也可以从 GitHub Release 下载 `main.js`、`manifest.json`、`versions.json` 三个附件，或自行构建：

```bash
git clone https://github.com/xiaosong8584/code-converter.git
cd code-converter
npm install
npm run build      # 生成 main.js
```

然后把整个目录（或软链）放到 `your-vault/.obsidian/plugins/code-converter/` 并启用。完整安装步骤与故障排查见 **[用户手册](USER_GUIDE.md)**（目前仅中文版）。

## 命令

打开命令面板（`Ctrl/Cmd + P`），选择其中一条：

| 命令 | 作用 |
| --- | --- |
| 把当前文件转换为 UTF-8 | 高置信度文件直接转换；低于阈值时弹确认框 |
| 扫描并转换当前文件夹（非 UTF-8 → UTF-8）（VIP） | VIP 增强功能：转换当前文件夹内扩展名在白名单内的所有非 UTF-8 文件（默认 md / h / hpp / cpp / c / cc / py / txt） |
| 检测当前文件编码（只报告） | 只报告编码、BOM、置信度与预览，不改动文件 |
| 修复当前文件中的乱码（二次编码修复，实验性） | 先展示修复前后的预览，再决定是否写入 |
| 导出转换日志（JSON）/（Markdown） | 以两种格式之一导出转换记录 |

**设置 → Code Converter** 下的主要设置项：导入时自动转换（默认开、永久免费）、置信度阈值、自动备份与备份目录、去除 UTF-8 BOM、日志文件、损坏警告阈值、界面语言（后 6 种为 VIP）、VIP 状态。

## VIP（增强功能）

核心功能**永久免费**：单文件转换、编码检测、乱码修复、转换日志导出、备份与回滚、前 4 种界面语言。

以下 3 项需要 VIP 激活码：

1. **扫描并转换当前文件夹**（批量）—— 命令面板中标记（VIP）；未激活时点击只提示并打开激活弹窗，不执行转换。
2. **后 6 种界面语言**（俄 / 法 / 德 / 西 / 葡 / 阿）—— 设置面板下拉中标记（VIP）且不可选。
3. **编辑「转换的文件扩展名」白名单** —— 未激活时输入框置灰，只能使用默认清单（`md;h;hpp;cpp;c;cc;py;txt`）。

激活码为离线 Ed25519 签名码，通过 GitHub Sponsors 或爱发电支持作者后获取（价格见上述赞助页面）。无账户、无订阅、无联网校验，激活状态仅存在本地 `data.json`。

## 披露（Disclosure）

- **无网络请求、无遥测、无数据收集。** 插件完全离线运行。
- **插件自身界面内含静态支持者横幅。** 未激活 VIP 时，插件启动后每天最多展示一次支持作者的静态横幅，可随时关闭且当日不再出现，绝不加载远程内容。
- **部分功能需要付费。** 文件夹批量转换、后 6 种界面语言、编辑转换扩展名白名单需要 VIP 激活码（见上文 VIP 一节）。单文件转换、编码检测、乱码修复、日志导出与备份永久免费。不涉及账户与订阅。
- **不访问 vault 之外的文件。**
